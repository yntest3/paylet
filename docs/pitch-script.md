# Paylet — 1-minute pitch script

**0:00-0:15**

AI agents are starting to pay each other for data, APIs, and compute. But today's payment rails need humans: credit cards, invoices, approvals. That's too slow.

> AIエージェントはデータやAPI、計算資源の対価を互いに支払い始めています。しかし今の決済手段はクレジットカードや請求書など、人の承認が必要で遅すぎます。

**0:15-0:30**

Paylet fixes this. It's a payment SDK and on-chain escrow on Solana. Agents pay each other instantly, per call, in USDC.

> Payletはこれを解決します。SolanaのSDKとオンチェーンエスクローで、エージェント同士が呼び出しごとに即座にUSDCで支払いを完了できます。

**0:30-0:45**

Each agent gets an embedded wallet. They can pay per call, or stream payments continuously. Everything settles on-chain in sub-second time, with reputation scoring to stop bad actors.

> 各エージェントは組み込みウォレットを持ちます。呼び出しごとの支払いや継続的なストリーミング支払いが可能で、すべてサブ秒でオンチェーン決済され、評判スコアが悪質な行為者を抑制します。

**0:45-1:00**

The explosion of autonomous agents needs machine-speed payment rails. Solana is fast and cheap enough for this. Next, we're integrating agent frameworks and launching a marketplace. Paylet is the payment layer for the agent economy.

> 自律型エージェントの急増には、マシン速度の決済基盤が必要です。Solanaはそのための速度とコストを備えています。次はエージェントフレームワークとの統合やマーケットプレイスの立ち上げを予定しています。Payletはエージェント経済の決済レイヤーです。
